    Location Guide

    Partner-Related vs CPE Internal

    Partner-Related: Files tied to a specific faculty/school partnership and their courses/programs.

    CPE Internal: Files about running CPE as a unit, not tied to any specific partner.

    Definition & Approvals vs Production & Delivery

    Definition & Approvals: Files about getting a program started.

    Production & Delivery: Files about running an active program.

    Credential vs Occurrence Level

    Credential Level: Files that apply to ALL offerings.

    Occurrence Level: Files specific to a particular term's offering.
